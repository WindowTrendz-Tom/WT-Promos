1. Banner

Slim strip for the top of any page. Shows the main promo and links to /offers.

<div data-wt-promos="banner"></div>

2. Single card: main promo

Always the current main promo. Changes by itself when offers.js changes.

<div data-wt-promos="card"></div>

3. Single card: second promo

The second promo (the one marked secondary in offers.js).

<div data-wt-promos="card" data-slot="secondary"></div>

4. Double card: main + second promo (no images)

Two compact cards side by side. Text only by default.

<div data-wt-promos="double"></div>

5. Double card with images

<div data-wt-promos="double" data-images="show"></div>

5b. Double card with "Current Promotions" title above

Title block plus the two cards. Add data-images="show" as well if you want images.

<div data-wt-promos="double" data-heading="show"></div>

6. All offer cards

Every live offer as cards, no page header.

<div data-wt-promos="offers"></div>

7. Full /offers page

Use the text inside so search engines can read it. The script replaces it with the styled page.

<div data-wt-promos="page">
  <h1>Current Promotions</h1>
  <p>Current promotions on curtains, blinds and shutters from Window Trendz, plus finance options. Made and installed locally in Manawatu and the Lower North Island. Book a free measure and quote to find out which offer suits your home.</p>
</div>
